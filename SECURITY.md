# Security policy

## Supported versions

Only the latest revision of the `main` branch is supported during the
pre-`1.0` phase.

## Reporting

Do not open a public issue for a vulnerability. Use GitHub's private
vulnerability reporting feature. Include affected versions, reproduction steps,
impact and any suggested mitigation.

Never include Assetto Corsa credentials, proprietary game files, private driver
telemetry or personal data in a report.
