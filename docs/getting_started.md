# Getting started

## Requirements

The Python project requires **Python 3.12 or later**. Live driving requires
Windows, Assetto Corsa and the CSP Custom AI interface. See
[controls and actions](control.md) for the integration boundary.

Run the following commands from the repository root. If the virtual environment
does not exist yet, create it first:

```powershell
py -3.12 -m venv .venv
```

Activate it and install the development and documentation dependencies:

```powershell
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev,docs]"
```

The GUI dependencies are optional:

```powershell
python -m pip install -e ".[diagnostics]"
```

## Read the documentation locally

```powershell
python -m mkdocs serve
```

Open <http://127.0.0.1:8000>. Documentation edits trigger a rebuild. Restart the
server after adding Python modules or changing docstrings if the preview does
not refresh them. Press `Ctrl+C` to stop the server.

To build a static copy:

```powershell
python -m mkdocs build --strict
Start-Process .\site\index.html
```

The build does not start Assetto Corsa or import application modules. API pages
are generated by static analysis of the Python source.

## Check the installation without the simulator

```powershell
python -m pytest -q
python tools/validate.py predictor --training-step 50000 --plot
```

The tests do not require a running simulator. The predictor command inspects a
fresh, untrained model on synthetic data; it does not establish driving accuracy.

## Validate the live connection

Check the installation path, car and track in the
[training configuration](configuration.md). Close Assetto Corsa before launch:

```powershell
python tools/validate.py environment --config configs/training.toml --check-env --steps 10 --action 0 0.15
```

Select **Drive/Start** in the game and confirm the terminal prompt. The
validator runs resets and a short control sequence. Further checks are
available through `python tools/validate.py` and the
[environment validation guide](racing_environment.md#validation).

## Start an experiment

```powershell
Copy-Item configs/training.toml configs/experiment.toml
```

Edit the copy before running it. Set `training.total_timesteps` and the
[future reward schedule](reward.md#future-predictor-reward) explicitly. The
template requests 100 million steps and enables future rewards immediately;
use a small budget for an initial integration run.

```powershell
python -m assetto_corsa_ai.main train --config configs/experiment.toml
```

Every invocation creates a new directory under `runs/`. See
[training and evaluation](agent_training.md) for checkpoints, resume and evaluation.
